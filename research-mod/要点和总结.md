# Gouqi MGQP Research Mod 开发交接要点

## 项目定位

- 游戏：Monster Girl Quest Paradox 终章，RPG Maker VX Ace／RGSS3。
- 这是研究、调试和测试用修改器，不是平衡性 Mod。
- 修改剧情、队伍、成就、图鉴、物品和变量前先备份存档。
- MTool 对编码、字面量换行、长文本和窗口生命周期较敏感。

## 编码和编辑规范

- 代码注释必须使用英文；本项目通常不需要新增注释。
- Ruby 代码使用 RGSS3／Ruby 1.9 风格，避免现代 Ruby 语法。
- 游戏显示换行优先使用 `10.chr`；需要兼容已有文本时使用 `.gsub(92.chr + 'n', 10.chr)`。
- 修改后检查：`ruby -w -c Patch/zzzz_gouqi_Research_Mod.rb`。
- 不要修改或回退用户已有的无关改动，不要提交游戏本体、存档和日志。

## 继续开发原则

- 先读 `errors.txt` 和相关类的完整生命周期，再修复根因。
- 新窗口必须检查创建、显示、激活、返回、延迟销毁和 Scene 切换。
- 新增菜单时同步检查：显示文字、命令符号、处理器、帮助文字和关闭流程。
- 功能开关优先保持独立，避免未经确认接管原版菜单。
- 修改主补丁后先做 Ruby 语法检查，再让用户用 RPG Maker／MTool 实测。

## research-mod 第一层文件阅读摘要

- `使用说明.md`：说明 Mod 的加载方式、各菜单功能、数值输入与取消流程、备份建议、停用方式，以及自定义战斗、战斗信息、对白模拟等功能的限制。Mod 只加载 `Patch/zzzz_gouqi_Research_Mod.rb`，不直接修改 `Data` 数据库。
- `开发记录.md`：记录从项目识别、RGSS3 脚本导出、职业／种族字段确认，到菜单扩展、窗口生命周期、Actor 787 编队错误修复和角色图鉴候补管理的开发过程。关键原则是使用原版方法和末尾加载补丁，避免直接写入核心字段。
- `Custom_Talk_Window_Technical_Notes.md`：搭话模拟由角色、敌人、搭话三级列表组成；对白和选项交给原版消息系统；帮助窗口位于底部；选项窗口通过临时标记右对齐。窗口必须正确隐藏、激活、延迟销毁，避免 MTool 崩溃或输入冲突。
- `香水诱惑对话模拟技术说明.md`：香水模拟读取 `2000 + 敌人ID` 的公共事件，解析对白、选项、条件、图片和音效。选择索引为 0-based；空分支要继续 `404` 后节点；条件分支不能全部展开；图片使用 `$game_troop.screen`；模拟不会执行原事件的战斗结算和变量副作用。
- `MTool兼容注意事项.md`：长中文帮助文本要主动用 `10.chr` 换行；菜单名保持短小；避免超大 `contents`、异常控制符、已释放窗口引用和频繁重建窗口。原版正常而 MTool 无报错退出时，优先检查文本长度、窗口尺寸和生命周期。
- `RGSS窗口延迟销毁说明.md`：确认／取消回调中不要同帧直接 `dispose`；先隐藏并停用，再加入延迟销毁队列；实例变量设为 `nil`；场景结束时清空队列。`close` 只表示关闭动画，不等于释放资源。
- `787编队报错原因.md`：Actor 787 的问题来自编队类别排序对未登记类别返回 `nil`。当前补丁使用“优先级位置 + 类别名称”的稳定排序，并已确认数据库中的 `淫魔`、`ゾンビ` 类别可用。
- `形态事件扫描.md`：形态事件扫描结果，共记录 154 条 Persona 相关记录，属于辅助研究索引。
- `脚本目录.csv`：由导出工具生成的 300 段 RGSS3 脚本目录，包含脚本序号、名称、解压字节数、关键词命中和候选文件。
- `export_script_candidates.rb`：读取并解压 `Data/Scripts.rvdata2`，按职业／种族／补丁等关键词导出候选脚本；使用脚本数组序号生成稳定文件名，避免原始记录 ID 重复覆盖。
- `变量名称表.csv`、`开关名称表.csv`：游戏变量和开关的 ID—名称索引，用于调试菜单和事件分析，不应把成就数据误认为普通开关或变量。
- `设计和技术要点.txt`：新增功能应参考现有自定义战斗和好感度输入界面；大量 ID 使用分批列表，提供上一批、下一批、重新输入和返回；不要因默认输入 0 而错误禁用上一批。长文本必须截断或固定换行，MTool 注入的 Mod 文本也会被翻译；数值输入应支持取消，并优先复用系统已有实现。
- `候选脚本/`：脚本导出候选目录，存放从 `Data/Scripts.rvdata2` 中按关键词筛出的原版脚本，供定位战斗、队伍、职业、种族和事件逻辑。

## 2026-08-29 强制胜利开关
