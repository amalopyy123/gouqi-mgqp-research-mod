# Gouqi MGQP Research Mod

面向《Monster Girl Quest Paradox／もんむす・くえすと！Paradox》终章的研究、调试和测试用 RPG Maker VX Ace（RGSS3）补丁。

本项目主要用于查看游戏数据、测试事件条件、验证战斗机制以及辅助定位卡关问题。它不是面向正常流程的平衡性 Mod，使用前请务必备份存档。

## 功能概览

- 当前角色修改：等级、好感度、永久属性、职业、种族、形态和妖术。
- 角色与队伍：队伍人数、地图跟随人数、候补角色、全对话和形态条件测试。
- 资源工具：数值与货币、按 ID 获取物品／武器／防具、全部内裤、牛奶和结婚物品。
- 地图工具：任意地图传送、事件坐标、传送坐标记录、地图与事件检查。
- 剧情工具：开关与变量修改、战败事件查看、反省会查看和卡关处理。
- 战斗工具：自定义战斗、敌我双方信息、Cut-in 查看、战斗记录、对白模拟和战斗修改。
- 功能开关：偷盗必定成功、牛奶必定成功、物品必定掉落、必定入队、不遇敌、穿墙等。
- 音乐工具：查看当前 BGM／BGS／ME 信息，以及显示当前音乐悬浮窗。

## 使用环境

- 游戏：Monster Girl Quest Paradox 终章
- 引擎：RPG Maker VX Ace／RGSS3
- 工具：可加载 RGSS3 脚本补丁的 MTool 或同类工具
- 补丁文件名：`zzzz_gouqi_Research_Mod`

## 使用方法

1. 先备份整个 `Save` 文件夹，或至少备份当前使用的存档。
2. 确认游戏目录内已有 `Patch` 文件夹，并且其中包含游戏原本的 `Patch.rb` 等基础补丁文件。不要在没有基础文件的情况下单独创建或替换整个 `Patch` 目录。
3. 将 `zzzz_gouqi_Research_Mod` 放入游戏内的 `Patch` 目录。
4. 使用 MTool 或游戏现有的脚本加载方式加载补丁。
5. 进入游戏后打开研究修改器菜单。
6. 使用功能前先阅读帮助窗口；涉及剧情、成就、队伍和图鉴的数据建议单独保存测试存档。

## 移除 Mod

1. 先退出游戏，并在 MTool 或其他加载工具中取消加载本补丁。
2. 从游戏内的 `Patch` 目录中移除 `zzzz_gouqi_Research_Mod` 文件。
3. 重新启动游戏，确认研究修改器菜单不再出现。

不要将整个 `Patch` 目录删除或替换；其中的 `Patch.rb` 等原有文件属于游戏基础补丁。

移除脚本不会自动撤销已经写入存档的内容，例如角色属性、物品、开关、变量、队伍数据和功能开关状态。若要恢复修改前的状态，请加载使用本 Mod 前的备份存档。

## 与其他 Mod 的兼容

本 Mod 的部分功能可能与其他 Mod 重复，例如战斗显示、偷盗判定、掉落判定、不遇敌或战斗菜单扩展。出现重复显示、功能失效或报错时，优先在研究修改器菜单中关闭对应功能，再测试其他 Mod。

如果某个功能必须由其他 Mod 覆盖，或其他 Mod 需要在本 Mod 之后加载，可以通过修改脚本文件名来调整加载顺序。例如在文件名前增加或修改字母、数字前缀，让它在 MTool 的脚本列表中排在本 Mod 后面。实际顺序以 MTool 显示的加载顺序为准，调整后请重启游戏并单独测试。

建议每次只调整一个 Mod 的加载顺序，并保留原始文件名备份，避免无法判断冲突来源。
## 重要说明

### 这是研究修改器

过度修改可能改变原本的游戏体验，也可能跳过事件条件、改变队伍数据、影响图鉴或成就。建议优先使用独立测试存档，不要直接在唯一的通关存档上连续执行多个全局操作。

### 成就和图鉴

部分成就保存在独立的图鉴数据中，不是普通开关或变量。直接加入物品、角色或修改统计值，不一定等同于正常游戏流程中的获得记录。

### 内裤收集

修改器提供按防具 ID 范围补齐内裤的功能。直接获得物品只会加入库存，不会自动执行向パンツ先生展示内裤的事件，因此不能保证自动触发对应的内裤收集成就。

### 剧情卡关提示

研究修改器内置部分常见卡关处理。修改剧情开关或变量前，请确认地图、事件和变量名称，并先备份存档。错误修改可能导致事件重复、跳过或无法继续。

### MTool 与编码

MTool 对脚本编码、超长帮助文字、窗口层级和字面换行比较敏感。项目中的文字和窗口布局会尽量使用 RGSS3 兼容写法；如果加载翻译文件后出现异常，建议先关闭其他补丁，确认单独加载本补丁是否正常。

## 重要参考

- 圣山卡关：开关 `2479`「アモス聖山暗転」改为 OFF。
- 圣山相关：建议关闭原版不遇敌，并关闭开关 `100`「ワープOFFスイッチ」和开关 `2116`「アモス聖山飛び降りフラグ」。
- 新人类宴会卡关：变量 `1150`「サラサ空賊団イベント」改为 `17`，再与サラサ、爱丽丝对话。

## 安全建议

- 执行全角色、全队伍、全好感度或全物品操作前先保存。
- 修改开关和变量时只修改明确确认过的 ID。
- 战斗、剧情和成就测试尽量使用独立存档。
- 出现报错时保留 `errors.txt`、当前存档和加载的补丁列表，方便定位兼容问题。
