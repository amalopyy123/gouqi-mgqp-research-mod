# Gouqi MGQP Research Mod

面向《Monster Girl Quest Paradox／もんむす・くえと！Paradox》终章的研究、调试和测试用 RPG Maker VX Ace（RGSS3）补丁。

本 Mod 主要用于查看游戏数据、测试事件条件、验证战斗机制、修改角色和辅助定位卡关问题，不是面向正常流程的平衡性 Mod。使用前请务必备份存档。

## 使用环境

- 游戏：Monster Girl Quest Paradox 终章
- 引擎：RPG Maker VX Ace／RGSS3
- 加载工具：支持 RGSS3 脚本补丁的 MTool 或同类工具
- 主补丁文件：`zzzz_gouqi_Research_Mod.rb`

## 安装

1. 备份整个 `Save` 文件夹，或至少备份当前使用的存档。
2. 确认游戏目录中已有 `Patch` 文件夹和游戏原本的 `Patch.rb`。
3. 将 `zzzz_gouqi_Research_Mod.rb` 放入游戏的 `Patch` 文件夹。
4. 使用 MTool 或游戏现有的脚本加载方式加载补丁。
5. 进入游戏后打开“研究用修改器”。

不要删除、替换或单独重建整个 `Patch` 文件夹；`Patch.rb` 等文件属于游戏基础补丁。

## 功能概览

### 地图

- 哈比羽毛：提供原版地点列表和忽略部分条件的修改版地点列表。
- 引导之线：执行原版返回地上效果，不要求持有物品，也不消耗物品。
- 当前地图宝箱管理：查看当前地图的宝箱和壶，并执行可安全解析的物品容器操作。
- 宝箱内容提示：在未处理容器上显示怪物或物品图标；已处理容器保留原图标并叠加完成标记。
- 任意地图传送：按地图 ID 选择地图并传送。
- 自定义传送点：记录和管理常用地图、坐标及方向。
- 地图与事件检查：查看地图、事件、坐标和相关基础信息。

### 当前角色修改

- 切换当前角色。
- 严格同步当前人物等级。
- 修改当前人物好感度。
- 修改当前角色永久属性加成。
- 切换当前角色形态。
- 当前角色学习妖术。
- 当前角色学习技能：不受职业或种族学习记录限制，可浏览数据库中的普通技能。
- 当前角色学习能力：按战技、职技、魔法、防御、特殊和大师能力分类。
- 切换当前角色职业。
- 切换当前角色种族。
- 当前角色全职全种。
- 修改当前角色名字：使用自定义文字输入窗口，确定后立即刷新角色显示。
- 保存当前角色备份、恢复当前角色备份。

### 队伍与剧情

- 队伍编成人数上限。
- 地图跟随显示人数。
- 在队伍编辑中显示角色 ID。
- 将全部可入队角色加入候补。
- 全员好感度修改。
- 修改累计战斗数据和角色个人累计数据。
- 全对话浏览和条件测试。
- 魔王城形态变化改。
- 魔王城好感度修改。
- 魔王城赠送礼物改。
- 魔王城撒娇改：可播放原版场景，同时提供拒绝选项；修改版场景不会传送到地图 154。
- 魔王城移除候补。
- 女仆对话：调用原版女仆公共事件；直接取消结束后，在仍处于原地图的情况下返回研究修改器。

### 资源与数据

- 角色图鉴：查看角色、角色状态、候补状态和图片资源。
- 开关与变量修改。
- 数值与货币修改。
- 按 ID 获取物品、武器和防具。
- 获得全部内裤、牛奶、结婚物品和 CD。
- 合成改：浏览物品、武器、防具的合成产物和配方，可正常合成或跳过材料合成。
- 当前音乐信息：查看当前 BGM、BGS 和 ME 文件名。
- 当前音乐悬浮窗：在地图和战斗中显示当前音乐文件名。
- 图片资源覆盖：开启后优先读取 `GouqiGraphicsOverride` 中的同名图片；找不到时回退到原版 `Graphics` 图片。

### 战斗

- 自定义战斗：按敌人 ID 或队伍选择战斗。
- 战败事件查看。
- 反省会查看。
- 显示敌方信息：查看敌人能力、状态、掉落、偷窃、牛奶、图片和关联角色等信息。
- 显示我方信息：查看我方队员等级、HP、MP、职业、种族和状态。
- 显示双方 Cut-in。
- 显示战斗记录。
- 显示对白模拟：查看和组合战斗相关对白。
- 显示战斗修改菜单：修改战斗成员状态、Buff、敌人物品及候补状态等。
- 战斗强制胜利：将敌人判定为战斗不能并调用胜负判定流程。实际奖励、入队和事件结果仍以游戏当前结算条件为准。

### 消耗与功能开关

- 消耗类技能开关：料理、炼金术、魔本术、商技和 EX 物品等消耗设置。
- 无消耗料理。
- 我方攻击必中必杀。
- 移除伤害浮动：只移除战斗中 HP 伤害的 `damage.variance`，不影响命中、暴击、属性倍率或恢复数值。
- 偷盗必定成功。
- 牛奶获取必定成功。
- 物品必定掉落。
- 必定入队。
- 敌人诱惑事件禁止。
- 敌人诱惑事件无视 HP 条件。
- 敌我全员诱惑免疫。
- 战败后跳过败北事件。
- 穿墙模式。
- 不遇敌。
- 原版禁止遇敌开关。
- 防止鲁卡被事件强制置顶。

### 其他

- 实验功能：存放仍在测试中的功能。
- 卡关处理：提供部分已知剧情卡关的辅助处理。
- 自定义文字输入：支持平假名、片假名、英数和常用符号，支持删除、空格、确定和取消；输入内容可保存到存档。

## 自定义文字输入接口

脚本中提供通用入口：

```ruby
ResearchMod.open_text_input(
  key,
  title,
  default_text,
  max_chars,
  help_text
)
```

也可以传入代码块处理确定后的文字。回调返回 `false` 时不会关闭输入窗口，其他返回值会关闭窗口并返回上一场景。详细参数和示例请参阅 `research-mod/open_text_input说明.md`。

## 存档与风险

- 修改角色、队伍、好感度、物品、开关、变量和功能开关前请先保存。
- 全角色、全队伍、全好感度和全物品操作可能影响剧情、图鉴、成就或队伍判定。
- 直接获得内裤只会加入库存，不会自动执行向パンツ先生展示内裤的事件。
- 移除脚本不会自动撤销已经写入存档的数据；恢复修改前状态请加载备份存档。
- 战斗强制胜利不保证所有原版奖励或入队事件都按正常战斗流程执行。

## 已知卡关参考

- 圣山卡关：将开关 `2479`「アモス聖山暗転」改为 OFF。
- 圣山相关：建议关闭原版不遇敌，并关闭开关 `100`「ワープOFFスイッチ」和 `2116`「アモス聖山飛び降りフラグ」。
- 新人类宴会卡关：将变量 `1150`「サラサ空賊団イベント」改为 `17`，再与サラサ、爱丽丝对话。
- 蛭蟲細胞：物品 ID `282`。

## 移除 Mod

1. 退出游戏。
2. 在 MTool 或其他加载工具中取消加载本补丁。
3. 从游戏 `Patch` 文件夹中移除 `zzzz_gouqi_Research_Mod.rb`。

不要删除整个 `Patch` 文件夹。移除脚本后，已经写入存档的角色、物品、开关、变量和队伍数据仍会保留。

## 文件说明

Patch/

项目中的 `research-mod` 目录保存数据表、开发记录、技术说明和测试笔记，不是游戏运行所必需的文件。
